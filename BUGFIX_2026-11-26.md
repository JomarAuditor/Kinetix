# Bugfix - 2026-11-26

## Issue
Application crashed when navigating to the Movies page with the following error:
```
AttributeError: 'AppContext' object has no attribute 'library_service'
TypeError: FavoriteTracker.__init__() takes 1 positional argument but 2 were given
```

## Root Cause Analysis

1. **Wrong attribute name in MoviesPage**: The `movies_page.py` was trying to access `ctx.library_service`, but the actual attribute in `AppContext` is `ctx.library`.

2. **Incorrect FavoriteTracker initialization**: The `MoviesPage` was instantiating `FavoriteTracker(MEDIA_MOVIE)`, but `FavoriteTracker.__init__()` takes no arguments.

## Files Changed

### 1. `presentation/pages/movies/movies_page.py`

**Line 34 - Fixed library service access:**
```python
# Before:
self._library = ctx.library_service

# After:
self._library = ctx.library
```

**Line 37 - Fixed FavoriteTracker initialization:**
```python
# Before:
self._hearts = FavoriteTracker(MEDIA_MOVIE)

# After:
self._hearts = FavoriteTracker()
```
